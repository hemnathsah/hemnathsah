## What I'm working on

### 🖧 CCNA-Diagram-AI
A local-first project exploring ways to turn network requirements into validated network diagrams.

- Planning network topologies and allocating device ports.
- Checking device, port, link-speed, and media compatibility.
- Separating deterministic network validation from optional local-LLM assistance.
- Rendering topology diagrams for review and iteration.
- Exploring network protocols and concepts such as STP, LACP, ECMP, HSRP, and VRRP.

*Status: under active development. I aim to keep the network engine and validation rules as the source of truth.*

### 📚 CCNA Study Portal
A personal study workflow for organizing CCNA learning resources and making them easier to browse locally.

*Status: personal project / ongoing development.*

### 🧪 Realistic PC and network simulation
I am also exploring interactive simulated PC network settings and command-line workflows so lab exercises can better reflect how hosts are configured and troubleshoot networks.

*Status: iterative development; simulated behavior is not a replacement for a real operating system or production network.*
